# 小队模式（WorkBuddy 版）分享包 — 快速上手

这是"小队模式"技能的 **WorkBuddy 版**分享包：装好后，你在聊天里发一句口令，你当前的 WorkBuddy 就会作为"主理人"拆解任务，派给四个角色（探索 / 执行 / 评审 / 专家顾问）分工干活，最后由它验收。主理人不是额外的成员，就是你对话里的 WorkBuddy 自己。

安装**只需要一次性让 WorkBuddy 自己完成**，你几乎不用动手。

## 三步走

1. **解压**本压缩包（记住解压出来的文件夹位置；不解压直接发 zip 也行）。
2. **打开包里的 `PROMPT-TO-SEND.md`**，复制其中框内文字（记得把包的路径填进去），发给你的 WorkBuddy。它会自己完成导入和自检，然后**带你做一次角色模型选型**：把供应商、模型、思考强度完整列出来给你选，你确认后写进配置——**只选一次，以后不再问**。
3. 在新聊天里单独一行发送：

   ```text
   开启小队模式
   ```

   看到 `👾 已开启小队模式` 即成功，之后正常派活。退出发送 `退出小队模式`，查询状态发送 `查看小队状态`。

## 常用口令

| 口令（单独一行发送） | 作用 |
|---|---|
| `开启小队模式` 或 `$workbuddy-team-mode` | 启用小队模式 |
| `退出小队模式` | 关闭小队模式 |
| `查看小队状态` | 查询当前聊天是否启用 |

## 角色模型选型是怎么回事

安装结束时 WorkBuddy 会问你一次：四个角色（探索/执行/评审/专家顾问）分别用什么模型、什么思考档位。它会给你三套整体方案（均衡 / 经济 / 顶配）加单角色微调，你选一套、确认，就写盘固定下来。

**之后每次用小队模式都是直接读这份配置，不会再问你一遍。** 想改的话，直接让 WorkBuddy 改配置文件，或删掉配置重新选一次。

一点如实说明：WorkBuddy 平台目前不支持给每个角色硬性锁定模型，这份配置的实际作用是"记录你的选择意图 + 派发时按意图执行 + 需要更严格时你在 UI 的模型/档位选择器手动设"。想换模型随时可以在 UI 里换。

## 出问题了？

把 WorkBuddy 的回复原样发给分享者；或者按 `PROMPT-TO-SEND.md` 末尾那段话让 WorkBuddy 自己逐项排查。包里 `INSTALL-AI.md` 有完整的故障排查表（给 WorkBuddy 看的），`scripts/check-package.cjs` 是安装自检脚本。
