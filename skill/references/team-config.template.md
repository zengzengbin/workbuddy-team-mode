## 平台限制与执行方式（写入正式配置时本段原样保留）

WorkBuddy 平台当前不支持按成员固定模型：专家 frontmatter 无 model / thoughtLevel 字段，AgentTool 派发也不能指定模型。因此本配置的执行方式为三位一体：

1. **意图记录**：本文件记录用户为每个角色选定的模型与档位意图；
2. **派发声明**：主 Agent 用 AgentTool 派发时，在任务说明中写明"该角色应按本配置使用 X 模型 / Y 档位的标准执行"；成员 Agent 在其可用能力范围内对齐；
3. **UI 档位建议**：如需更严格的模型/档位控制，请在 WorkBuddy UI 的模型下拉与思考档位选择器中手动设置（具体入口以用户 WorkBuddy 实际 UI 为准）。

## 一次性初始化声明（写入正式配置时本段原样保留）

本配置为**一次性初始化**：安装选型时写入一次，之后每次使用小队模式主 Agent 直接读取本文件，**绝不重复询问选型**。仅当本文件缺失或损坏（缺角色行、存在未替换占位符、表格无法解析）时，才按 `skill/references/model-menu.md` 重新走一次选型。用户想修改配置时，可直接编辑本文件，或删除本文件后重新触发选型。
